# Portfolio 🌐

My 10th assignment during the Front-End Development track at Route Academy.

This project focused on adding interactive functionality to a pre-designed portfolio using JavaScript.

## ✨ Features

* Dark and Light Mode
* Custom color themes
* Font selection
* Theme and font preferences saved using LocalStorage
* Active navigation links while scrolling
* Scroll-to-top button
* Settings sidebar
* Portfolio filtering by category
* Testimonials carousel

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* LocalStorage
